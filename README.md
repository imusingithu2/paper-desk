# 📈 Paper Desk

A mobile-first PWA paper-trading simulator for iPhone 17. Trades real live market data with fake money using an automated bot strategy.

## 🚀 Deployment to Vercel

1.  **Push to GitHub**: Create a repository and push this code.
2.  **Import to Vercel**: Connect your GitHub account and select the `paper-desk` repo.
3.  **Deploy**: Vercel will automatically detect Vite. Click **Deploy**.

## 📱 Add to Home Screen (iPhone)

1.  Open the deployed URL in **Safari**.
2.  Tap the **Share** button (square with arrow).
3.  Scroll down and select **Add to Home Screen**.
4.  Launch from your home screen for a full-screen, standalone experience.

## 💻 LAN Testing

To test on your physical iPhone while developing:
1.  Run `npm run dev -- --host` in your terminal.
2.  Find your local IP (e.g., `192.168.1.50`).
3.  On your iPhone, navigate to `http://192.168.1.50:5173`.
